# dotfiles

Modern macOS development environment. Zsh + Neovim + tmux + VSCode + Claude.

Originally forked from [Mathias Bynens' dotfiles](https://github.com/mathiasbynens/dotfiles), fully modernized for 2025+.

## What's included

| Category | Tools |
|----------|-------|
| **Shell** | Zsh with [zinit](https://github.com/zdharma-continuum/zinit) + [Powerlevel10k](https://github.com/romkatv/powerlevel10k) |
| **Terminal** | iTerm2 + tmux (Claude-themed, TPM plugins, session persistence) |
| **Editors** | VSCode (primary) + Neovim (terminal, with LSP/Telescope/Treesitter) |
| **Git** | [delta](https://github.com/dandavison/delta) diffs, [lazygit](https://github.com/jesseduffield/lazygit) TUI, modern config |
| **CLI tools** | eza, bat, fd, ripgrep, fzf, zoxide, jq, httpie, and more |
| **Python** | [uv](https://github.com/astral-sh/uv) (replaces pip/virtualenv/pyenv) |
| **Obsidian** | Vault helpers, quick capture, fzf search, obsidian.nvim |
| **AI** | Claude Code aliases and shell integration |

## Quick start

```bash
# 1. Clone
git clone https://github.com/vmereuta/dotfiles-osx.git && cd dotfiles-osx

# 2. Install Homebrew packages
bash brew.sh

# 3. Sync dotfiles to ~
bash bootstrap.sh

# 4. Configure prompt
p10k configure

# 5. Install tmux plugins (in tmux, press Ctrl-a + I)
```

## Structure

```
.zshrc          # Zsh config (zinit, plugins, completions, tool integrations)
.zshenv         # Zsh env vars (XDG, PATH dedup)
.zprofile       # Login shell (Homebrew, PATH, GNU tools)
.tmux.conf      # tmux config (Claude theme, TPM, vi keys, session restore)
.aliases        # Shell aliases (modern CLI, git, docker, obsidian, claude)
.functions      # Shell functions (fzf-powered, obsidian helpers, utilities)
.exports        # Environment variables (editors, fzf, python, obsidian)
.gitconfig      # Git config (delta, aliases, VSCode merge/diff tools)
.vimrc          # Vim config (minimal, for quick edits)
.config/nvim/   # Neovim config (lazy.nvim, LSP, Telescope, Treesitter)
.config/Code/   # VSCode settings (Catppuccin, vim mode, formatters)
.editorconfig   # EditorConfig (per-language indent rules)
brew.sh         # Homebrew package installer
bootstrap.sh    # Dotfile sync script
```

## Customization

- `~/.path` - Extend `$PATH`
- `~/.extra` - Private config (not committed)
- `~/.p10k.zsh` - Powerlevel10k prompt config (generated by `p10k configure`)
- `$OBSIDIAN_VAULT` - Set in `.exports` to your vault path

## iTerm2 setup

1. Set font to **MesloLGS Nerd Font** (Preferences > Profiles > Text)
2. Import color scheme from `init/Solarized Dark.itermcolors` or use Catppuccin
3. Enable shell integration: iTerm2 > Install Shell Integration
